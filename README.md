# MScan v0.4 — Clean Build

This clean repository contains:
- custom native magnetometer plugin
- custom Camera2 + TextureView plugin
- HTML/CSS/JavaScript UI
- GitHub Actions APK build

Build:
1. Upload the contents of this folder to a clean GitHub repository.
2. Commit to main.
3. Open Actions.
4. Download MScan-Android-APK after a successful run.
